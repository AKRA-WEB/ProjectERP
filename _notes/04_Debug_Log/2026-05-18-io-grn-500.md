# Debug Log — GRN 500 Error (IO Receive)

**Trigger:** `POST https://project-erp-kokx.vercel.app/api/grn 500 (Internal Server Error)` when receiving IO

---

## Root Cause (Actual)

**SQL batch INSERT placeholder stride mismatch in `app/api/grn/route.ts`**

When `unit_cost` column was added to `grn_line_items` INSERT (Migration 036), the
params loop was updated to push 10 values per row, but the SQL placeholder stride
was NOT updated — still used `i * 9 + offset`.

```typescript
// BROKEN: stride = 9, params per row = 10
.map((_, i) => `($1, $${i * 9 + 2}, ..., $${i * 9 + 10}, ${i + 1})`)
// Only 9 slots (indices 2–10), but loop pushes 10 values
// → row 2 params overwrite row 1 → PostgreSQL gets wrong column count → 500
```

```typescript
// FIXED: stride = 10
.map((_, i) => `($1, $${i * 10 + 2}, ..., $${i * 10 + 11}, ${i + 1})`)
// 10 slots per row matches 10 values pushed per row
```

**Columns in INSERT (12 total):**
`grn_id` ($1, shared) + 10 per-row dynamic + `line_number` (hardcoded `${i+1}`)

## Secondary Finding (Confirmed Non-Issue)

Original plan suspected `handleReceive` in `inbound-orders/[id]/page.tsx` missing

`payload.inbound_order_id = ioIdParam`. Plan was wrong — code was correct.
