# Track: wms-search-nav-fix — Fix WMS Product Search & Navigation 404

## Goal
Fix broken product search functionality in Inbound Orders and resolve the 404 error when clicking the breadcrumb home icon.

## Root Cause Analysis
1.  **Search Failure (IO):** `app/app/inbound-orders/new/page.tsx` expects the API response to be wrapped in `{ data: ... }`, but the `api-client` already unwraps it, leading to `undefined` results.
2.  **Navigation 404:** The Home icon in `components/layout/TopBar.tsx` links to `/app/menu`, which is failing (possibly due to route group structure or middleware).
3.  **Breadcrumb Consistency:** Breadcrumbs are generated by splitting the path, which may lead to invalid intermediate links if not properly mapped to the actual route structure.
