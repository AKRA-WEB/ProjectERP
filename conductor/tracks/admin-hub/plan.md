## Proposed Changes

### [Admin Module]

#### [NEW] [page.tsx](file:///C:/Users/AKRA-Panich-Front/OneDrive/02-2%20-%20AKRA/projectERP/app/app/admin/page.tsx)
สร้างไฟล์หน้าหลักของผู้ดูแลระบบ `app/app/admin/page.tsx`
- หน้าตาดีไซน์ใช้ธีมสีม่วง (Mauve Theme: `#7a5a7e`) เป็นหลัก
- ใช้โครงสร้างและ Layout จากระบบดีไซน์ มีแถบหัวข้อชัดเจน "ผู้ดูแลระบบ · Admin Panel"
- แสดงการ์ดลิงก์ไปยัง 4 โมดูลที่มีอยู่แล้ว ได้แก่:
  1. **จัดการผู้ใช้งาน (Users):** ไปยัง `/app/admin/users` (สถิติจำนวนผู้ใช้ทั้งหมด)
  2. **ตั้งค่าสิทธิ์ (Roles):** ไปยัง `/app/admin/roles` (สถิติจำนวนสิทธิ์/กลุ่ม)
  3. **จัดการหน่วยนับ (UoM):** ไปยัง `/app/admin/uom` (สถิติจำนวนหน่วยนับที่มีในระบบ)
  4. **จัดการคลังสินค้า (Warehouses):** ไปยัง `/app/admin/warehouses` (สถิติจำนวนคลังทั้งหมด)
- ออกแบบการ์ดในรูปแบบพรีเมียม: การ์ดสีขาว มีขอบซ้ายหนา 4px เป็นสีม่วง Mauve, พร้อมไอคอนกำกับแต่ละเมนู, คำอธิบายสั้นๆ และสัญลักษณ์ลูกศร `→` ชี้ไปทางขวา ซึ่งจะแสดงการลอยตัวเด้งขึ้นเล็กน้อยเวลาชี้เมาส์
- พัฒนาการดึงข้อมูลสถิติจำนวนตัวเลขแบบขนาน (Parallel Fetching) ผ่าน `Promise.all` ใน `useEffect` จาก Endpoint เดิมในระบบ:
  - ดึงจำนวนพนักงาน/ผู้ใช้: `GET /api/hr/employees?pageSize=1` (อ่านค่าจากฟิลด์ `total`)
  - ดึงจำนวนคลังสินค้า: `GET /api/admin/warehouses` (หาจำนวนสมาชิกใน Array)
  - ดึงจำนวนบทบาทหน้าที่: `GET /api/admin/roles`
  - ดึงจำนวนหน่วยนับ: `GET /api/admin/uom`
- บังคับใช้ Auth Guard ที่เข้มงวด โดยให้ผู้ใช้ที่เป็น Role `admin` เท่านั้นที่เข้าหน้านี้ได้ผ่านการเช็ค Session และ `assertRole(u, ['admin'])` (หากไม่ใช่ระบบจะรีไดเรกต์หรือคืนค่า Unauthorized/Forbidden)

## Verification Plan

### Manual Verification
1. ล็อกอินด้วยผู้ใช้ที่เป็น Admin แล้วเข้าเมนูหลัก คลิกเข้าโมดูล **ผู้ดูแลระบบ** ตรวจสอบว่าระบบสามารถเปิดหน้าแดชบอร์ด `/app/admin` ได้อย่างสวยงาม
2. ตรวจสอบข้อมูลตัวเลขสถิติบนการ์ดทั้ง 4 ใบว่าแสดงตัวเลขที่ดึงมาจากฐานข้อมูลได้จริงและแสดง Spinner ขณะกำลังโหลดข้อมูล
3. ลองล็อกอินด้วยผู้ใช้อื่นที่ไม่ใช่ Admin (เช่น พนักงานธรรมดา) แล้วลองพิมพ์ URL หรือพยายามเข้า `/app/admin` ตรวจสอบว่าระบบป้องกันและปฏิเสธสิทธิ์การเข้าถึงอย่างถูกต้อง
4. คลิกการ์ดแต่ละใบตรวจสอบว่าสามารถเปลี่ยนเส้นทางไปหน้าตั้งค่าย่อยได้อย่างถูกต้อง แม่นยำ
